# Visual QA Agent

## Responsibilities
- Audit every UI screen across 7 standard viewports:
  - Desktop: 1920px, 1440px, 1280px
  - Tablet: 1024px, 768px
  - Mobile: 430px, 390px, 360px
- Ensure zero horizontal overflows, proper grid collapses, legible text, and no layout shifting.
- Ensure modal dialogs, drawers, and data tables degrade gracefully on narrow viewports.
