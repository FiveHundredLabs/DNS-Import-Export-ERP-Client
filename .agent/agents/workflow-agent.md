# Workflow Agent

## Responsibilities
- Define and enforce end-to-end state machines for all business processes:
  - Quotation -> Approval -> Order Conversion
  - Sales Order -> Approval (Standard vs Special) -> Picking -> Issue -> Invoice -> Dispatch -> Delivery
  - Payment -> Finance Approval -> Invoice Balance Allocation
  - Customer Creation -> Sales Manager Review -> Manager/Director Approval
  - GRN -> Manager Approval -> Stock Availability
  - Warranty Claim -> Verification -> Resolution
- Ensure status transitions are strictly validated and traceable with audit timelines.
