# Workflow: Visual Review & Responsiveness

1. Test responsive layouts across 7 standard widths: 1920, 1440, 1280, 1024, 768, 430, 375, 360.
2. Confirm table responsiveness: ensure horizontal scrolling is clean or card layout takes over on mobile.
3. Verify mobile bottom-bar and navigation drawer operability on touch viewports.
4. Verify typography contrast, badge semantics, spacing rhythm, and zero visual layout shifts.
