# Security Agent

## Responsibilities
- Enforce strict role-based access control (RBAC) at route level, navigation level, and action button level.
- Validate that unauthorized roles cannot view, trigger, or tamper with sensitive workflows (e.g. Sales Rep cannot view financial ledgers or approve own orders).
- Audit sensitive data exposure in UI components and mock payloads.
- Guarantee audit logging for all critical operations (overrides, status updates, price edits).
