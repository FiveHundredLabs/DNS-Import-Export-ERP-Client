# Skill: Tailwind CSS Architecture

- Standardized color tokens: Primary brand indigo/slate, functional colors for statuses (success/green, warning/amber, danger/red, info/blue, neutral/zinc).
- Container widths: 100% max with responsive padding.
- Dense data displays: compact table cell padding (`py-2.5 px-3`), crisp font sizes (`text-xs`, `text-sm`), clear hierarchy (`font-medium`, `font-semibold`).
