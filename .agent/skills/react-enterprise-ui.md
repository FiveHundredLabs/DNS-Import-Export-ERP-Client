# Skill: React Enterprise UI

- Use modern React 19 / 18 features (hooks, composition, ErrorBoundaries, Suspense).
- Avoid monolithic components. Separate stateful container hooks from pure presentational components.
- Keep business calculations inside `src/rules/` and data fetching inside `src/services/` & `src/hooks/`.
- Maintain clean TypeScript types across all components with zero `any` usage.
