# Page Quality Checklist

- [ ] Document title and breadcrumbs set
- [ ] Responsive navigation and mobile drawer functioning
- [ ] No horizontal viewport overflow on 360px width
- [ ] Tab navigation and keyboard focus rings visible
- [ ] All table headers sortable or cleanly aligned
- [ ] Actions menu accessible with aria attributes
- [ ] Modals and dialogs trap focus and close on Escape
- [ ] Empty states show helpful icon, clear title, and primary CTA
