# UX Engineer Agent

## Responsibilities
- Architect intuitive user journeys for all 8 roles (Director, Manager, Sales Manager, Finance Manager, Area Manager, Sales Rep, Stock Keeper, Cashier).
- Design clear information hierarchies, reducing unnecessary clicks.
- Enforce meaningful empty states with actionable primary buttons, skeletons for loading, and explicit error states with recovery actions.
- Craft mobile ergonomics for field Sales Reps (thumb zones, prominent bottom/hub actions, swipe/tap accessibility).
